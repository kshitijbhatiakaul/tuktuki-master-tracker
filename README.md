# Tuktuki Master Tracker

One page that pulls every Tuktuki report together, in six sections with tabs:

| Section | Tabs | Sources |
|---|---|---|
| Dashboard | Monthly highlights (month check-boxes), key numbers for a date range, revenue & business, what the data says | Adjust, admin panel, Daily Ads report, Business Performance Tracker |
| App insights | Installs & uninstalls, retention, viewing & drop points, session time, packages, renewals, rewarded ads & AdMob, channel quality, observations | Adjust, admin panel, Business Performance Tracker |
| Demographics | Audience, age & gender, locations & language, interests & devices, timings, channel quality, observations | Google Analytics (+ BigQuery export), Business Performance Tracker |
| Series | How each series performs, viewership by show, gainers & losers, promotion vs viewing, observations | admin panel, Daily Ads report (Creative Analysis), Instagram & YouTube logs |
| Social media | Instagram & YouTube overviews (the report's charts rebuilt), post / video logs, what works, suggestions | Instagram & YouTube report, Business Performance Tracker |
| Performance marketing | Overview, weekly & monthly (all metrics), one tab per Daily Ads report sheet, influencers & casting | Daily Ads report, Influencer dashboard |

`docs/index.html` is the built page (a static snapshot; open it in a browser). It is refreshed every Monday
together with the User Behaviour dashboard — see [REFRESH.md](REFRESH.md).

Private repo, no GitHub Pages.
